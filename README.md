O aplicativo app.py, foi desenvolvido objetivamente para realizar uma avaliação de saneamento ![saneamento](https://img.shields.io/badge/saneamento-blue?logo=saneamento&logoColor=blue) consumo responsável, de acordo com o tipo de imóvel:

 Comercial ![imóvelcomercial](https://img.shields.io/badge/imovelcomercial-red?logo=imovelcomercial&logoColor=red)
 Residencial - Casa  ![casa](https://img.shields.io/badge/casa-blue?logo=casa&logoColor=blue)
 Residencial - Apartamento  ![apartamento](https://img.shields.io/badge/apartamento-blue?logo=apartamento&logoColor=blue)

O sistema foi desenvovido em Phyton ![phyton](https://img.shields.io/badge/phyton-blue?logo=phyton&logoColor=blue)

A execução se dá primeiramente, definindo o tipo específico de imóvel, sendo validadas apenas uma das três letras definidas:

    C - Comercial
    H - Casa
    A - Apartamento

    Qualquer outra letra, fará o programa insistir em qual tipo de imóvel deve ser definida pelo usuário.

A continuidade do sistema, se dará apenas ao escolher H ou A para os imóveis residenciais.

Neste momento ao informar a unidade de consumo em m3, o sistema retornará as devidas recomendações.
