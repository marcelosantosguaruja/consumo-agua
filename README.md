O aplicativo app.py, foi desenvolvido objetivamente para realizar uma avaliação de consumo responsável, de acordo com o tipo de imóvel:
 Comercial
 Residencial - Casa
 Residencial - Apartamento

O sistema foi desenvovido em Phyton

A execução se dáprimeiramente definindo o tipo específico de imóvel, sendo validadas apenas uma das três letras definidas:

    C - Comercial
    H - Casa
    A - Apartamento

    Qualquer outra letra fará o programa insistir em que o usuário.

A continuidade do sistema, se dará apenas ao escolher H ou A para os imóveis residenciais.

Neste momento ao informar a unidade de consumo em m3, o sistema retornará as devidas recomendações.
